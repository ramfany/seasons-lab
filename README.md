# 계절 변화의 원인을 찾아라! 🌍☀️

6학년 2학기 과학 「1. 계절의 변화」의 **「계절 변화의 원인을 찾아라!」** 지구본 4개 실험을
진짜 지구와 태양으로 해 보는 3D 웹 시뮬레이션입니다.

## 바로 열기
- GitHub Pages를 켜면 `https://(아이디).github.io/(저장소 이름)/` 에서 열립니다.
- `index.html` 파일 하나에 모든 것이 들어 있어서, 내려받아 브라우저로 바로 열어도 됩니다.

## 구성
- **실험하기**(10단계, 배지 10개): 준비 확인 → 문제 파악 → 예상하기 → 실험 설계 → 실험①(자전축 수직) → 실험②(자전축 23.5°) → 결과 정리 → 계절 찾기 → 결론 → 적용
- **자유 탐구**: 날짜, 시각, 자전축 기울기, 관측 위치(서울·부산·시드니·싱가포르)를 바꿔 보기
- **미션**: 8가지 탐구 미션

## 권장 환경
- 크롬 또는 엣지 최신 버전(WebGL이 필요합니다)
- 1920×1080 화면 권장. 태블릿과 휴대폰에서도 열립니다.
