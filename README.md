# 계절 변화의 원인을 찾아라! 🌍☀️

6학년 2학기 과학 「1. 계절의 변화」의 **「계절 변화의 원인을 찾아라!」** 지구본 4개 실험을
진짜 지구와 태양으로 해 보는 3D 웹 시뮬레이션입니다.

## 바로 열기
- GitHub Pages를 켜면 `https://(아이디).github.io/(저장소 이름)/` 에서 열립니다.
- `index.html` 파일 하나에 모든 것이 들어 있어서, 내려받아 브라우저로 바로 열어도 됩니다.

## 구성
- **실험하기**(11단계, 배지 11개): 생각 열기 → 준비 확인 → 문제 파악 → 예상하기 → 실험 설계 → 실험①(자전축 수직) → 실험②(자전축 23.5°) → 결과 정리 → 계절 찾기 → 결론 → 적용
  - **생각 열기**: “여름엔 태양과 가까워서 덥다?” — 1월 초(약 1억 4700만 km, 가장 가까움)와 7월 초(약 1억 5200만 km, 가장 멂)의 거리를 재고, 서울 평균 기온(1월 약 −2 °C, 7월 약 25 °C)과 견주며 인지 갈등을 일으킵니다.
  - **우주 화면 확대·지구 옮기기**: 왼쪽 위 우주 화면의 ＋/－로 「전체 → 지구 가까이 → 측정기 확대」까지 가까이 볼 수 있고(마우스 바퀴·지구 두 번 누르기도 가능), 확대한 채 공전해도 시점이 지구를 따라가 가~라 어디서나 측정기의 그림자가 보입니다. 「🌍 지구 옮기기」 가·나·다·라 단추로 실험 중에도 지구를 옮겨, 이미 잰 곳의 그림자와 바로 비교할 수 있습니다.
- **자유 탐구**: 날짜, 시각, 자전축 기울기, 관측 위치(서울·부산·시드니·싱가포르)를 바꿔 보기. 「태양까지 거리」를 켜면 가장 가까운 곳·가장 먼 곳이 보이고, 1년 그래프에 「태양 거리」가 있습니다.
- **미션**: 10가지 탐구 미션(태양과 가장 가까운 날, 밤인 곳은 겨울일까?, 서울과 부산의 해 높이 등 오개념 미션 포함)
- **스토리 모드(게임) · 사라진 계절을 찾아서**: 계절이 사라져 시들어 가는 2087년의 지구. 인공지능 ZERO가 「여름은 태양과 가까워서 덥다」고 믿고 9일 뒤 지구를 태양 쪽으로 옮기려 합니다(D-9). 학생은 나만의 대원으로 꾸민 뒤(피부색·머리 모양·옷·모자·가방·호버 휠체어 등 다양한 선택) 기지를 걸어 다니며 9개의 장을 해결하고, 실험으로 모은 증거 카드로 ZERO와 **증거 대결**을 세 번 벌여 지구를 구합니다. 화면 위 **지구 생명력** 막대와 기지 곳곳의 **생명의 씨앗** 6개, 실제 위성 영상으로 만든 **지구 관측 모형**이 있고, 실험실 관측소에서도 내 대원을 방향키·WASD·누르기로 움직여 그림자 끝을 잴 수 있습니다. 모든 임무를 마치면 기지에서 **🪐 궤도 조종기**로 지구를 직접 공전시켜 계절(풍경·해 높이·그림자·음악)을 바꿀 수 있고, 미니게임 **📸 계절 찰칵!**(공전하는 지구를 보고 주문한 계절·때에 맞춰 사진 찍기, 남반구 시드니 주문 포함)이 열립니다. ‘멸망 위기’와 ZERO는 흥미를 위한 가상 설정이며, 과학 내용(거리·남중 고도·자전축·남반구)은 실제와 같습니다. 진행 상황은 그 기기의 브라우저에 저장돼요.
- **조작법 연습**(14단계): 처음 열면 화면 돌리기·확대·보는 방향·공전·자전 보기 등을 직접 눌러 보며 익힙니다. 위쪽 **?** 단추로 다시 할 수 있습니다.
- **배경 음악·효과음**: 음원 파일 없이 브라우저(Web Audio)가 그 자리에서 만들어 연주합니다(저작권 걱정 없음). 장면마다 곡이 바뀝니다(실험하기·자유 탐구: 잔잔한 우주 탐사 곡 / 미션: 경쾌한 도전 곡 / 스토리: 수수께끼 → 긴급 뉴스 → 계절 잃은 기지 → 실험실 → 자전축 엔진 → 엔딩 팡파르, 계절이 돌아온 뒤에는 계절별 악기·자연 소리). 정답 「딩동댕」, 오답 「땡」, 거리 재기 숫자 소리, 「어? 이상한데?」 소리, 인물별 말소리, 바닥별 발소리 등이 들어 있고, 큰 효과음이 날 때는 음악이 잠깐 작아집니다. 위쪽 🎵(음악)·🔊(효과음) 단추로 따로 끄고 켭니다. 소리가 끊기거나 찢어지지 않도록 음악은 효과음과 다른 오디오 장치(넉넉한 버퍼)에서 미리 예약해 연주합니다.

## 새 버전으로 바꾸기
1. 저장소에서 **Add file → Upload files**를 누릅니다.
2. 새 `index.html`을 끌어다 놓습니다. 같은 이름이라 옛 파일이 새 파일로 바뀝니다.
3. **Commit changes**를 누르고 1~2분 기다립니다(진행 상황은 **Actions** 탭).
4. 사이트에서 **Ctrl+F5**(맥은 Cmd+Shift+R)로 새로 고칩니다.

## 권장 환경
- 크롬 또는 엣지 최신 버전(WebGL이 필요합니다)
- 1920×1080 화면 권장. 태블릿과 휴대폰에서도 열립니다.
